# 既有改动的源码归属与迁移

先阅读现有实现与匹配版本的上游，再把运行时逻辑放回所属组件。QML、Rust、标准配置和独立权限边界均可保留；把相同shell命令换成C++不能算原生迁移。

## 已删除的旧实现

独立键盘Python策略、桌面Python策略及各自用户服务、三指libinput/uinput桥接器及其服务/udev规则、桌面QML手势层、任务效果中的Dock状态发布器、旧system-sleep桌面恢复脚本、旧档位锁屏脚本和对应测试已删除。打包器只生成原生版，基础镜像不再安装这些旧文件。已有配置中的已知旧入口仅在一次性迁移时清理，不承担运行时策略。

设备当前旧进程仍承担已锁定会话的输入；不能通过删掉正在使用的输入链路或强退桌面完成切换。先完成新包、私有备份与检查，再由用户保存应用并正常退出/登录，安装时删除设备上的旧副本。Git历史和私有回退包保留，不作为运行时兼容分支。

## 运行与回退

构建方法见各组件README。桌面部署包同时包含匹配的触控插件和一次性迁移工具，安装后不用另外启动Python策略服务。新的KWin/Plasma必须通过正常重新登录加载；不得强制重启当前会话或绕过锁屏。依次复验PIN输入/热插拔、时钟页/密码页软键盘、控制中心上滑及滑条/列表例外、无键盘抽屉搜索、三指选窗、Dock三段手势。

回退使用部署前匹配deb和私有配置备份；在正常退出会话后恢复，不能在运行中覆盖整份桌面配置。密码、硬件认证材料、输入学习库、Wi-Fi配置和用户截图不得公开。安装/备份/诊断工具仍保留，均不作为常驻桌面策略。
