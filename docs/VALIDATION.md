## 本次源码发布检查

`scripts/check-project.py` 检查 Python AST、JSON/XML/SVG、Markdown 本地链接、敏感文件/常见凭据模式及原生电源源文件的固定哈希。CI 还验证 shell 语法、编译隐私过滤器并运行原生Dock/手势归属测试，以及从固定上游打包控制中心/任务效果。PowerDevil原生C++只在匹配的ARM64/Qt环境编译并运行6项CTest；CI源码检查不代替这个原生构建。`test_power_policy.py` 在有KDE配置工具的Linux中执行3项隔离迁移测试，其他环境明确跳过；旧Python策略测试随旧实现移除，原生Rust的13项测试与KWin独立输入接口测试另行记录。这些检查不能替代实机 UI、驱动编译和刷机测试。

本次发布不重新刷写平板、不重新生成完整 rootfs，也没有为了解锁输入验收退出用户会话。2026-11-15 已在本机热部署 Linexin 和原生 guard，最终全屏与 Dock/导航结果由用户确认；横竖屏、多屏、休眠恢复和 USB/蓝牙外设仍待独立回归。公开部署的面板识别应在新设备上重新验证。详细构建与限制见[抽屉说明](DESKTOP_DRAWER.md)。
